Интегратор PackTuning — одна точка входа

Опишите задачу или выберите программу

Интегратор собирает установленные программы PackTuning в одном окне. Нажмите нужную иконку для запуска или введите задачу и исходные данные в центральное поле, затем нажмите «Выполнить».

Если подходящая установленная программа определена однозначно, она запустится автоматически. Для задачи из нескольких этапов появятся ссылки на программы в порядке выполнения; неоднозначный запрос можно уточнить или выбрать предложенный инструмент вручную.

На иллюстрации оставлены Раскройщик, Калькулятор гофроящиков, ГофроТехкарта, Справочник ГОСТов и расчёт по ГОСТ 9142-2014. Справочник ГОСТов и расчёт по ГОСТ 9142-2014 входят в подарок в любой комплект. Передача параметров зависит от поддержки интеграции и редакции целевой программы.

Частые вопросы

Что входит в комплект?

Раскройщик в полной версии, Калькулятор гофроящиков Standard и ГофроТехкарта Standard.

Программы автоматически передают данные друг другу?

В «Старт» включены Standard-редакции Калькулятора и ГофроТехкарты. Интеграция с ними из Раскройщика требует PRO-редакций. Подберите расширенный комплект с автором.

Нужен ли SQL Server?

Для демо Раскройщика — нет. Рабочая версия Раскройщика хранит данные в SQL Server. Калькулятор сохраняет настройки и справочники в файлах.

Это подписка?

Нет. Цена 199 000 ₽ указана за бессрочные лицензии комплекта на одно рабочее место с привязкой к компьютеру.

Можно попробовать перед покупкой?

Да. В разделе «Демоверсии» есть отдельные ссылки на все три программы.
