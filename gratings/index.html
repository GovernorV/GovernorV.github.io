Ответы на вопросы

Frequently asked questions

Что меняет демоверсия?What changes in the demo?

После нажатия «Рассчитать» длина, ширина и высота решётки случайно изменяются в пределах ±10% и округляются до целых миллиметров. Новые значения видны в полях.

After Calculate, the assembly length, width and height change randomly within ±10% and are rounded to whole millimetres. Updated values appear in the input fields.

Можно ли сохранить обе схемы в PDF?Does the PDF include both drawings?

Да. Меню «Вывод результатов → Отчёт в PDF» сохраняет параметры и результаты, чертёж перегородок и укладку на поддон.

Yes. Results output → PDF report exports input data and results, partition drawings and the pallet layout.

Что означает высота загрузки?What does loading height mean?

Это полезная высота продукции, без высоты самого поддона.

It is the available product loading height, excluding the pallet itself.

Нужен ли интернет для расчёта?Do calculations need an internet connection?

Расчёт выполняется локально в настольной программе Windows.

Calculations run locally in the Windows desktop application.
