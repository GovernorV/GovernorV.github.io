Возможности программы

Program features

FEFCO

Расчёт по конструкции

FEFCO calculation

Выберите тип ящика, задайте длину, ширину, высоту и число изделий на штампе. Для 0201 доступен общий участок ножа по формуле ПОЯС.

Select a box type, enter length, width, height and items per die. The 0201 calculation can account for a shared cutting section using the POYAS formula.

DWG

Чертёж DWG / DXF

DWG / DXF drawings

Загружайте чертёж напрямую, назначайте слои реза, биговки и перфорации. Выберите масштаб и укажите, содержит ли файл весь штамп или одно изделие.

Read drawings directly and assign cutting, creasing and perforation layers. Set the scale and specify whether the file represents the entire die or a single item.

Наглядная развертка

Color-coded preview

Режущие ножи показаны красным, биговка — синим пунктиром, перфорация — зелёным. Переключайтесь между библиотекой и загруженным чертежом.

Cutting rules are red, crease rules are blue dashed lines and perforation is green. Switch between the template library and an imported drawing.

Стоимость штампа

Die cost estimate

Задайте тариф за метр для каждого вида ножей, постоянные расходы и наценку. Знак валюты выбирается отдельно и не выполняет курсовой пересчёт.

Set a per-metre rate for each rule type, fixed costs and markup. Choose a currency symbol separately; this does not perform currency conversion.

Сохраните исходные данные, длины ножей, стоимость и цветной чертёж в PDF. Отчёт сразу открывается в вашей программе просмотра.

Save inputs, rule lengths, cost breakdown and the color drawing to PDF. The report opens immediately in your PDF viewer.

Расчёт штампа внутри PackTuning

Die costing inside PackTuning

Открывайте «Ножемер» кнопкой «…» из Калькулятора гофроящиков или ГофроТехкарты. Тип ящика, размеры и число изделий передаются автоматически. «Применить» возвращает стоимость штампа в вызывающую программу.

Open KnifeMeter using the “…” button in Box Price Calculator or GofroTechCard. Box type, dimensions and items per die are passed automatically. Apply returns the die cost to the calling program.

При отдельном запуске доступны расчёт и PDF-отчёт. Кнопка «Применить» появляется только в режиме интеграции полной версии.

Standalone mode provides calculation and PDF reports. Apply is available only when the full edition is launched through an integration.

Дежурство: расчёт без ручного запуска

Watch mode: automatic job processing

Ножемер PRO следит за каталогом и обрабатывает поступающие JSON-задания. В одном потоке можно чередовать расчёты FEFCO и чертежи DWG/DXF: режим и все параметры задаются в самом JSON.

KnifeMeter PRO watches a directory and processes incoming JSON jobs. Mix FEFCO calculations and DWG/DXF drawings in the same workflow: each JSON specifies its calculation mode and parameters.

По конструкции FEFCO

By FEFCO design

"source": "parametric"

Тип ящика, размеры, число изделий на штампе, раскладка, тарифы, расходы и наценка передаются в задании.

The job supplies box type, dimensions, items per die, layout, rule rates, fixed costs and markup.

По чертежу DWG/DXF

From a DWG/DXF drawing

"source": "drawing"

JSON задаёт путь к чертежу, масштаб и слои реза, биговки и перфорации. Можно указать весь штамп или одно изделие. Относительный путь считается от каталога JSON.

The JSON supplies the drawing path, scale and cutting, creasing and perforation layers. Choose an entire die or a single item. Relative paths are resolved from the JSON directory.

Настройте наблюдение

Configure watching

Выберите каталог, имя файла — например input.json — и интервал проверки от 1 до 3600 секунд в меню «Дежурство».

In the Watch mode menu, choose a directory, filename such as input.json, and a polling interval from 1 to 3600 seconds.

Передайте JSON

Submit a JSON job

PRO дождётся завершения записи файла и рассчитает длины ножей и стоимость штампа по параметрам задания.

PRO waits for the file to finish being written, then calculates rule lengths and die cost using the job parameters.

Получите результаты

Collect the results

В каталог отчётов сохраняются PDF с цветным чертежом и JSON результата. Уникальные имена сохраняют историю расчётов.

The report directory receives a PDF with the color drawing and a JSON result. Unique filenames preserve the calculation history.

Освободите очередь

Clear the queue

После успеха входной JSON удаляется или переносится в архив — по вашему выбору. При ошибке он сохраняется, дежурство приостанавливается, причина записывается в журнал.

After success, the input JSON is deleted or moved to an archive, as configured. On error it is preserved, watching pauses, and the reason is logged.

Дежурство работает, пока PRO запущен; окно можно свернуть. Автоматические PDF не открываются, а исходные DWG/DXF остаются на месте. В демоверсии и при запуске из интеграции дежурство недоступно.

Watching runs while PRO is open; the window can be minimized. Automatic PDFs do not open, and source DWG/DXF files stay in place. Watch mode is unavailable in the demo and during integration launches.

В образце DWG/DXF замените drawing.path и имена слоёв на значения своего чертежа.

In the DWG/DXF sample, replace drawing.path and the layer names with those of your drawing.

What you can try in the demo

Доступны конструкции FEFCO, PDF-отчёт и три тестовых чертежа: 0201, 0204 и 0427. При каждом расчёте длина, ширина и высота случайно изменяются в пределах ±10% и подставляются в поля.

Try FEFCO templates, PDF reports and three sample drawings: 0201, 0204 and 0427. Each calculation randomly changes length, width and height within ±10% and substitutes the new values in the fields.

Произвольные чертежи и передача стоимости через интеграцию доступны в полной версии. Изменённые тестовые образцы не принимаются. Заставка, значок и PDF демоверсии отмечены DEMO.

Importing your own drawings and returning costs through integrations require the full edition. Modified sample drawings are rejected. The demo splash screen, icon and PDF carry a DEMO mark.
