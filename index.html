PACKTUNING PRO

Программы работают как единая система

Интеграция убирает повторный ручной ввод между проектированием, расчётом стоимости и транспортной укладкой. Исходная программа собирает данные текущего заказа в JSON-файл и открывает целевой PRO-модуль уже с заполненной формой и выполненным расчётом.

PACKTUNING PRO

The programs work as one system

Integration eliminates repeated manual entry between design, costing and transport stacking. The source program collects the current job data into a JSON file and opens the target PRO module with its form prefilled and the calculation completed.

Как проходит интеграция

1Проверка установки

Кнопка интеграции отображается только тогда, когда соответствующая PRO-программа установлена в системе.

2Формирование задания

Размеры, количество, профиль гофры, тип изделия и другие доступные параметры заказа записываются во временный JSON-файл.

3Интерактивный запуск

JSON передаётся программе как параметр командной строки. Поля заполняются автоматически, программа делает расчёт и остаётся открытой для проверки и изменения условий.

4Продолжение работы

Пользователь меняет параметры, пересчитывает и формирует отчёты. В отличие от режима дежурства, исходный файл не удаляется после молчаливой обработки.

Что передаётся по каждой связи

Справочник ГОСТов ⇄ расчётные модули

Справочник передаёт номер ящика, ГОСТ и внутренние размеры в Раскройщик, Фасовщик PRO, Паллетировщик PRO, Калькулятор PRO, ГофроТехКарту PRO и расчёт предельной нагрузки. В каждой из этих программ команда «Выбрать из ГОСТа» открывает справочник в режиме выбора и возвращает размеры обратно.

Раскройщик → ГофроТехКарта PRO

Из свойств заказа передаются тип изделия, размеры ящика и заготовки, количество, тип и марка картона, профиль, цвета и другие заполненные производственные данные. Технологическая карта открывается с готовой исходной записью.

Раскройщик → Калькулятор PRO

Для ящика передаются внутренние размеры, количество, профиль и марка картона. Для типа «Гофрозаготовка» Калькулятор автоматически открывается в режиме «Гофролист» и получает длину и ширину самой заготовки — размеры ящика не требуются.

Раскройщик → Паллетировщик PRO

Ящики передаются в обычный режим укладки. Гофрозаготовки открываются в режиме расчёта пачек: длина пачки равна половине длины заготовки, ширина — ширине заготовки, в пачке 30 листов, а высота рассчитывается по профилю гофры. Поля размеров ящика при этом остаются пустыми.

Фасовщик PRO → Паллетировщик PRO

Команда «Укладка на поддон» передаёт рассчитанные размеры заполненного ящика, количество ящиков и связанные параметры упаковки. Паллетировщик сразу показывает вариант транспортной укладки, не требуя повторно набирать данные.

ГофроТехКарта PRO → Паллетировщик PRO

Из текущей техкарты передаются геометрия и тираж ящика, профиль гофры и доступные параметры изделия. Это связывает разработку конструкции с проверкой количества ящиков на поддоне.

Калькулятор PRO ⇄ Паллетировщик PRO

Паллетировщик запускается в режиме пачек и получает размеры пачки, количество заготовок в пачке, профиль и тираж. Пользователь может изменить условия укладки; непосредственно перед закрытием Паллетировщик возвращает актуальный результат в поле «Количество пачек на поддоне» Калькулятора.

Без лишних сообщений при старте. Если автоматический первый расчёт невозможен из-за неполных или несовместимых условий, целевая программа просто открывается с подставленными данными без сообщения об ошибке — параметры можно поправить вручную.

How the integration works

1Installation check

An integration button is shown only when the corresponding PRO application is installed on the computer.

2Job creation

Dimensions, quantity, flute profile, product type and other available order fields are written to a temporary JSON file.

3Interactive launch

The JSON path is passed as a command-line argument. The target application fills its fields, calculates automatically and stays open for review and adjustments.

4Continue working

The user can change parameters, recalculate and create reports. Unlike watch mode, the job is not silently processed and deleted.

Data flow for each connection

GOST Standards Guide ⇄ calculation modules

The guide sends the box number, GOST and internal dimensions to OptCutting, OptPacker PRO, Palletizer PRO, Cost Calculator PRO, GofroTechCard PRO and Box Strength Calculator. In each application, “Select from GOST” opens the guide as a picker and returns the dimensions.

OptCutting → GofroTechCard PRO

The job supplies product type, box and blank dimensions, quantity, board type and grade, flute profile, colors and other populated production data. The tech card opens with the source record ready for work.

OptCutting → Cost Calculator PRO

Box jobs supply internal dimensions, quantity, flute profile and board grade. A corrugated blank automatically opens the Calculator in sheet mode and supplies the blank length and width, so box dimensions are not required.

OptCutting → Palletizer PRO

Boxes use standard pallet stacking. Corrugated blanks use bundle mode: bundle length is half the blank length, width equals blank width, each bundle contains 30 sheets and bundle height is calculated from the flute profile. Box dimension fields remain empty.

OptPacker PRO → Palletizer PRO

The “Pallet stacking” command transfers the calculated filled-box dimensions, box quantity and related packaging parameters. Palletizer immediately displays the transport stacking arrangement without repeated data entry.

GofroTechCard PRO → Palletizer PRO

The current tech card supplies box geometry and production quantity, flute profile and available product parameters. This connects structural design with the pallet quantity check.

Cost Calculator PRO ⇄ Palletizer PRO

Palletizer opens in bundle mode and receives bundle dimensions, sheets per bundle, flute profile and job quantity. Conditions can be changed; immediately before closing, Palletizer returns the current result to the Calculator’s “Bundles per pallet” field.

No unnecessary startup dialogs. If the first automatic calculation cannot be completed because input conditions are incomplete or incompatible, the target application simply opens with the supplied values and lets the user correct them manually.
