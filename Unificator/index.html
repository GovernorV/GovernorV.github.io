Унификатор гофроящиков

Corrugated Box Unifier

Программа подбирает общий тип и размеры гофроящика для группы разных изделий — с учётом ограничений, ГОСТов, стоимости материала и параметров транспортной укладки.

Windows software that selects one shared corrugated-box type and size for a group of different products, taking constraints, standards, material cost and transport layout into account.

Что решает Унификатор

What the Unifier solves

Программа проводит технолога по всему расчёту: от списка изделий до сравнения двух готовых вариантов упаковки.

The software guides a packaging engineer from the product list to a side-by-side comparison of two finished packaging options.

◎

Группа изделий

Product group

Объединяйте изделия разных форм и размеров; исходные данные можно импортировать из Excel.

Combine products of different shapes and sizes, with source data imported from Excel when needed.

▤

ГОСТы и типоразмеры

Standards and sizes

Выбирайте нормативы и стандартные ряды через встроенный справочник.

Select applicable standards and dimensional series through the built-in directory.

◇

Конструкция ящика

Box construction

Задавайте тип FEFCO, картон, профиль гофры, число слоёв и доступные форматы.

Set the FEFCO type, board, flute profile, number of layers and available formats.

⌁

Поиск общего решения

Shared solution search

Стандартный поиск распределяет все изделия по совместимым группам и находит общий ящик.

Standard search groups compatible products and finds a shared box for every group.

Случайный поиск исследует нестандартные размеры и показывает улучшение выбранного критерия.

Random search explores custom dimensions and reports the improvement in the selected criterion.
