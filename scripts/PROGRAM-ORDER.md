# Единый порядок программ PackTuning

Источник порядка: `assets/program-order.json`. Метаданные, цены, названия, иконки и URL остаются в существующих реестрах.

После изменения списка:

```sh
node scripts/sync-program-order.cjs
node scripts/sync-program-order.cjs --check
node scripts/test-program-order.cjs
```

Синхронизация встраивает список в `index.html` и `assets/program-garland.js`, обновляет ItemList, совместимый снимок `prs/assets/programs.json` и версии подключений общего скрипта. Дополнительных сетевых запросов и асинхронных зависимостей при просмотре сайта нет. Новую программу нужно зарегистрировать в существующих реестрах метаданных и один раз включить в общий список.

Каталог: 22 программы по общему списку, затем `gostbundle` только в карточках и ItemList. Страница программы: `[currentId, ...GLOBAL_PROGRAM_ORDER.filter(id => id !== currentId)]`, отсутствующие метаданные пропускаются.

Удалены RELEVANCE, ручные splice-перестановки гирлянд и карточек, индивидуальные CSS style.order карточек. Удалены неиспользуемые renderGarland и fetch(programs.json) из ПРС. Защита общего скрипта не допускает повторного создания гирлянды. Тематические рекомендации не менялись; оформление гирлянд и CSS сохранены.

## Проверено 22 октября 2026

- Просканированы все 70 HTML-страниц и JS/JSON-файлы доступного репозитория.
- Автоматизированный тест выполняет настоящий общий скрипт для всех 22 маршрутов на RU/EN (44 варианта): порядок, переключение языка, активная иконка 72 px, единственный экземпляр, ссылки и существование файлов иконок.
- Проверены сортировка карточек, все 23 позиции ItemList и отсутствие независимой гирлянды ПРС.
- В браузере проверены 14 доступных страниц на обоих языках (28 вариантов), каталог на RU/EN и совпадение последовательности карточек и навигации.
- Временная перестановка двух ID в единственном исходном JSON с повторной синхронизацией и тестами подтвердила распространение изменения. Утверждённый порядок восстановлен.
- Горизонтальная прокрутка, активное выделение и темы используют существующий CSS без изменения дизайна.
